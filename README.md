# Biblia Rápida

Uma maneira simples e rápida de encontrar versos bíblicos.

## Funcionalidades

- Busca por livros, capítulos e versículos
- Interface responsiva

## Instalação

```bash
git clone https://github.com/seu-usuario/biblia.git
cd biblia
npm install
npm start
```

## Tecnologias

- Typescript
- React
- Vite
